### Описание функций

#### 1. **`generate_maze(width, height)`**
   - **Назначение**: Генерация лабиринта.
   - **Описание**: Эта функция создает двумерный массив ячеек, представляющих лабиринт. Используется алгоритм поиска в глубину для создания связанных путей и стен. Каждая ячейка имеет стены, которые могут быть удалены для создания проходов.
   - **Входные параметры**:
     - `width` — ширина лабиринта в ячейках.
     - `height` — высота лабиринта в ячейках.
   - **Выходные данные**: Возвращает сгенерированный лабиринт в виде двумерного массива объектов `Cell`.

#### 2. **`load_player_sprites()`**
   - **Назначение**: Загрузка спрайтов игрока.
   - **Описание**: Функция загружает изображения игрока для различных направлений движения и состояний (например, плач, сон). Спрайты хранятся в словаре для удобного доступа.
   - **Входные параметры**: Отсутствуют.
   - **Выходные данные**: Возвращает словарь с загруженными изображениями игрока.

#### 3. **`draw_maze(maze)`**
   - **Назначение**: Отрисовка лабиринта.
   - **Описание**: Функция проходит по всем ячейкам лабиринта и рисует их стены на экране.
   - **Входные параметры**: `maze` — двумерный массив объектов `Cell`, представляющих лабиринт.
   - **Выходные данные**: Отрисовка лабиринта на экране.

#### 4. **`draw_player(player_x, player_y, current_sprite)`**
   - **Назначение**: Отрисовка игрока.
   - **Описание**: Функция рисует игрока на экране в заданных координатах, используя текущий спрайт.
   - **Входные параметры**:
     - `player_x` — координата X игрока.
     - `player_y` — координата Y игрока.
     - `current_sprite` — текущий спрайт игрока.
   - **Выходные данные**: Отрисовка игрока на экране.

#### 5. **`draw_goal(goal_x, goal_y)`**
   - **Назначение**: Отрисовка цели.
   - **Описание**: Функция рисует цель (выход из лабиринта) на экране с анимацией вспыхивающего неонового света.
   - **Входные параметры**:
     - `goal_x` — координата X цели.
     - `goal_y` — координата Y цели.
   - **Выходные данные**: Отрисовка цели на экране.

#### 6. **`draw_spirits(spirits)`**
   - **Назначение**: Отрисовка духов.
   - **Описание**: Функция проходит по списку духов и рисует каждого на экране.
   - **Входные параметры**: `spirits` — список объектов `Spirit`, представляющих духов.
   - **Выходные данные**: Отрисовка духов на экране.

#### 7. **`draw_shortest_path(path, player_x, player_y)`**
   - **Назначение**: Отрисовка кратчайшего пути.
   - **Описание**: Функция рисует стрелки, указывающие кратчайший путь от текущей позиции игрока до цели. Стрелки мигают неоновой расцветкой.
   - **Входные параметры**:
     - `path` — список координат, представляющих кратчайший путь.
     - `player_x` — координата X игрока.
     - `player_y` — координата Y игрока.
   - **Выходные данные**: Отрисовка стрелок на экране.

#### 8. **`draw_timer(time_left)`**
   - **Назначение**: Отрисовка таймера.
   - **Описание**: Функция отображает оставшееся время на экране.
   - **Входные параметры**: `time_left` — оставшееся время в миллисекундах.
   - **Выходные данные**: Отображение таймера на экране.

#### 9. **`draw_congratulations()`**
   - **Назначение**: Отрисовка экрана поздравлений.
   - **Описание**: Функция отображает экран поздравлений с анимацией переливающегося текста.
   - **Входные параметры**: Отсутствуют.
   - **Выходные данные**: Отображение экрана поздравлений на экране.

#### 10. **`draw_hearts(hp, timer_started)`**
   - **Назначение**: Отрисовка сердец (жизней).
   - **Описание**: Функция отображает количество жизней игрока на экране. Если таймер запущен, сердечки не отображаются.
   - **Входные параметры**:
     - `hp` — количество жизней игрока.
     - `timer_started` — флаг, указывающий, запущен ли таймер.
   - **Выходные данные**: Отображение сердец на экране.

#### 11. **`mode_2()`**
   - **Назначение**: Основной игровой цикл для режима 2.
   - **Описание**: Функция реализует основной игровой цикл, в котором происходит обработка событий, движение игрока и духов, проверка столкновений, отрисовка элементов игры и управление таймером.
   - **Входные параметры**: Отсутствуют.
   - **Выходные данные**: Игровой процесс в режиме 2.

#### 12. **`congratulations_screen()`**
   - **Назначение**: Отображение экрана поздравлений при достижении цели.
   - **Описание**: Функция отображает экран поздравлений, воспроизводит музыку и завершает игру.
   - **Входные параметры**: Отсутствуют.
   - **Выходные данные**: Отображение экрана поздравлений и завершение игры.

#### 13. **`heuristic(a, b)`**
   - **Назначение**: Вычисление эвристической оценки расстояния между двумя точками.
   - **Описание**: Функция возвращает Манхэттенское расстояние между точками `a` и `b`, чтобы оценить расстояние от текущей клетки до конечной.
   - **Входные параметры**:
     - `a` — текущая клетка.
     - `b` — конечная клетка.
   - **Выходные данные**: Манхэттенское расстояние между `a` и `b`.

#### 14. **`find_shortest_path(maze, start_x, start_y, goal_x, goal_y)`**
   - **Назначение**: Поиск кратчайшего пути в лабиринте.
   - **Описание**: Функция реализует алгоритм A* для нахождения кратчайшего пути в лабиринте от стартовой точки до конечной. Она использует приоритетную очередь для отслеживания пути с наименьшими затратами.
   - **Входные параметры**:
     - `maze` — структура данных лабиринта.
     - `start_x` — начальная координата X.
     - `start_y` — начальная координата Y.
     - `goal_x` — конечная координата X.
     - `goal_y` — конечная координата Y.
   - **Выходные данные**: Возвращает путь от начальной до конечной точки в виде списка координат.

### Общее описание геймплея и взаимодействия между функциями

Игра начинается с генерации лабиринта с помощью функции `generate_maze`. Затем загружаются спрайты игрока и инициализируются начальные координаты игрока и цели. В режиме 2 (`mode_2`) происходит основной игровой цикл, в котором обрабатываются события (движение игрока, нажатие клавиш), проверяются столкновения с духами, обновляются позиции духов и отрисовываются все элементы игры.

Если игрок нажимает клавишу "F", включается режим отображения кратчайшего пути, и запускается таймер. Функция `find_shortest_path` используется для нахождения кратчайшего пути от текущей позиции игрока до цели, а `draw_shortest_path` отображает этот путь на экране.

Если игрок достигает цели, вызывается функция `congratulations_screen`, которая отображает экран поздравлений и завершает игру. Если время истекает или игрок теряет все жизни, игра также завершается с соответствующим сообщением.

### Описание функционала духов и их характеристика

#### 1. **Дух Моня**
   - **Характеристика**: Добрый, но глупый дух.
   - **Описание**: Моня пытается отправить игрока в конец лабиринта, но каждый раз путает начало с концом. В результате, игрок возвращается к старту.
   - **Функционал**:
     - При столкновении с игроком, игрок возвращается к начальной точке лабиринта.
     - Реализуется в методе `affect_player` класса `Spirit`.

#### 2. **Дух Соня**
   - **Характеристика**: Спящая и умиротворяющая.
   - **Описание**: Соня заражает игрока своим настроем, заставляя его отдыхать на пару секунд. Это создает помеху, особенно если игрок использует подсказку кратчайшего пути.
   - **Функционал**:
     - При столкновении с игроком, игрок засыпает на несколько секунд.
     - Реализуется в методе `affect_player` класса `SlowSpirit`.

#### 3. **Дух Нафаня**
   - **Характеристика**: Подстрекатель и фантомас.
   - **Описание**: Нафаня отправляет игрока на случайную точку на карте, создавая неожиданные и запутанные ситуации.
   - **Функционал**:
     - При столкновении с игроком, игрок телепортируется на случайную точку лабиринта.
     - Реализуется в методе `affect_player` класса `TeleportSpirit`.

   - **Описание**: Создает объект духа с заданными координатами, путем движения и спрайтом.

     - `x` — начальная координата X.
     - `y` — начальная координата Y.
     - `path` — путь, по которому движется дух.

   - **Описание**: Дух движется по заданному пути, обновляя свои координаты.

   - **Выходные данные**: Обновленные координаты духа.

#### 3. **`Spirit.draw(self)`**
   - **Назначение**: Отрисовка духа на экране.

### Общее описание взаимодействия духов с игроком

В игре присутствуют три типа духов, каждый из которых оказывает уникальное влияние на игрока:

1. **Дух Моня**: Возвращает игрока к началу лабиринта, создавая повторные попытки прохождения.
2. **Дух Соня**: Усыпляет игрока на несколько секунд, создавая временные задержки в движении.
3. **Дух Нафаня**: Телепортирует игрока на случайную точку лабиринта, создавая неожиданные и запутанные ситуации.

Каждый дух имеет свой путь движения, который определяется при инициализации. Взаимодействие с игроком происходит в методе `affect_player`, который реализует специфичное поведение для каждого типа духа.
